# CartoLegend progress

This repository hosts the public, plain-language progress page for CartoLegend, a research effort that turns scanned geologic maps into structured geospatial data.

[View the progress page](https://lockntoad.github.io/cartolegend-progress/)

The page reports measured results, failed approaches, corrections, and their limits. Results are updated in place when later checks show that an earlier statement was incomplete or wrong. Private fleet operations and account telemetry are intentionally excluded.
